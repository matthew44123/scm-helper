# scm-helper
a script for tf2 providing various links,better visuals for checking effects on Steam Community Market

Requires [Tempermonkey](https://www.tampermonkey.net/)

Uses [Pricedb](https://docs.pricedb.io/)'s API for pulling skus

Click [This Link](https://github.com/matthew44123/scm-helper/raw/main/scm-helper.user.js) after installing Tempermonkey to install the script
